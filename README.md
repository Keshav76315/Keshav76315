# Philosophy

I enjoy understanding how software works beneath the surface.

Rather than only building applications, I like building the systems that applications rely on.

Whether it's a browser engine, an AI pipeline, backend infrastructure or developer tooling, I prefer working from first principles and understanding every layer of the stack.
